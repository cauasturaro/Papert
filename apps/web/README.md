# Web

Papert's user interface, built with Next.js and React.

- Provides registration, login and account screens.
- Displays study steps, files and the code editor.
- Sends tutor requests and shows progress and responses.
- Analyzes saved attempts and shows syntax errors, criterion feedback, hints and history.

Web communicates with Core through its API routes.

See the [project README](../../README.md) for setup and startup commands.
